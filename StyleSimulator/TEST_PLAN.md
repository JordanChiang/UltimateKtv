# StyleSimulator 跑馬燈與提示功能測試計劃 (Test Plan)

本測試計劃旨在提供完整的驗證程序，用以驗證 `StyleSimulator` (樣式模擬器) 各項跑馬燈、點播提示、字體樣式與參數組合在修改後均能穩定正常工作。

---

## 一、 測試目標與重點

1. **重覆次數 (Repeat Count) 與間隔時間 (Hold Time) 組合測試**：驗證設定 1 次、多次 (2~10 次) 及 0 次 (關閉) 時，滾動、停頓與結束收尾是否皆正常；特別驗證從 0 次切換回 1~10 次時均能正常即時觸發播放。
2. **間隔時間單位**：驗證「間隔時間」單位全面改為 `秒` (`0 ~ 5 秒`)，與 `settings.json` (毫秒) 保持雙向精準轉換。
3. **參數動態調整實時反應測試**：驗證拖曳滑桿 (次數、速度、間隔、字級) 時，預覽畫面是否能即時重新播放並呈現最新數值。
4. **範本視窗樣式與格式標示**：驗證 4 個範本視窗是否皆為「靠左對齊、垂直置中、高度統一 42px」，且底部有 `參數:` 前綴標示。
5. **同排互斥與佇列排隊測試**：驗證點播成功提示顯示期間，不會與跑馬燈重疊；提示結束後不會錯誤再次播放舊跑馬燈。
6. **字粗細中文選單與設定檔讀寫相容性**：驗證 `標準`、`中等`、`半粗體`、`粗體`、`特粗體`、`極粗體` 顯示與 `settings.json` 讀寫正常。

| 測試案例編號 | 重覆次數 (PlayCount) | 間隔時間 (HoldTime) | 測試操作步驟 | 預期結果 (Expected Results) |

| **TC-01** | `1 次` | `1 秒` | 1. 滑桿設為 1 次、1 秒<br>2. 點擊「🎵 播放跑馬燈 (1:有待播)」 | 文字自右側滾入至左側離開 **1 次**，離開後立即結束，狀態顯示 `狀態: 跑馬燈播放完畢`，畫面恢復乾淨。 |
| **TC-02** | `1 次` -> `2 次` | `1 秒` | 1. 執行完 TC-01 後<br>2. 將重覆次數滑桿拉至 **2 次** | 滑桿調整時畫面**即時重新觸發播放**，文字完整滾動 **2 次**，兩次之間在幕後間隔 1 秒，完成後正常收尾。 |
| **TC-03** | `2 次` -> `0 次 (關閉)` | `1 秒` | 將重覆次數滑桿拉至 **0 次** | 狀態提示 `狀態: 跑馬燈播放次數設為 0 (關閉)`，動畫立刻停止，參數說明列清空。 |
| **TC-04** | `0 次` -> `1 次 / 3 次` | `2 秒` | 1. 在 0 次關閉狀態下<br>2. 將重覆次數滑桿拉至 **1 次**，再拉至 **3 次** | 從 0 切換至 1 次或 3 次時，**動畫能重新正常發起**，分別正確播放 1 次與 3 次，每次間隔 2 秒。 |
| **TC-05** | `1 次` | `0 秒` | 間隔設為 0 秒，次數設為 1 次 | 文字滾過 1 次後無幕後等待，直接結束並顯示 `狀態: 跑馬燈播放完畢`。 |
